# Galil Setup Tool - Single Executable with Icon

## Quick Start

1. **Run the executable**: Double-click `Galil_Setup_Tool.exe`
2. **Automatic setup**: The program will install dependencies automatically
3. **Connect controller**: Use USB or Ethernet connection
4. **Use the application**: Follow the GUI for network configuration and motor tuning

## System Requirements

- Windows 10/11 (64-bit)
- Internet connection (for dependency installation)
- Galil DMC-4143 or DMC-4103 controller

## What Happens When You Run It

1. **Dependency Check**: Automatically checks for required Python packages
2. **Auto-Install**: Installs pyserial and psutil if needed
3. **File Extraction**: Extracts all application files
4. **Application Launch**: Starts the Galil Setup Tool GUI

## Features

- Complete standalone executable with custom icon
- Automatic dependency management
- No manual installation required
- Full GUI interface
- Network configuration and discovery
- Motor tuning and setup
- Command validation
- Real-time status monitoring

## Troubleshooting

- If the executable doesn't start, try running as administrator
- Ensure you have an internet connection for dependency installation
- For controller connection issues, check USB/Ethernet cables
- Ensure Windows Defender or antivirus isn't blocking the executable

## Support

This is a complete standalone application with automatic setup.
No Python installation required on the target system.
